## [7.1.0] - 2026-11-24

> **Minor**: nueva vía de instalación y actualización. El README ya no lista los comandos `/plugin`: da un prompt para copiar que apunta a `INSTALL.md`, y Claude sigue esas instrucciones.
>
> - **Adoptantes**: nada que hacer. Para ponerte al día, puedes usar el prompt del README.

### Added
- **`INSTALL.md`** (raíz): instrucciones dirigidas a Claude para instalar o actualizar Neb.
  - **Requisitos**: Git Bash en Windows, localizado por `CLAUDE_CODE_GIT_BASH_PATH` o junto a `git.exe`; no por `where bash`, que suele dar el de WSL. Python 3 con SQLite ≥ 3.35.5 como `python` o `python3` desde Git Bash, el mismo intérprete del `SessionStart`; `py` y el alias de la Microsoft Store no cuentan.
  - **Detección**: con `claude plugin list --json`, o con `installed_plugins.json` como respaldo, de cualquier `neb@<marketplace>` en cualquier `scope`. Si hay varias copias, un menú para desactivar o desinstalar las sobrantes.
  - **Instalación**: `neb@neb`, o `neb@<name>` cuando el equipo tiene marketplace propio, con verificación al final.
  - **Actualización**: la referencia es la `source` del plugin en su marketplace (`main` de `stradinov/neb` salvo `ref` o `sha` fijos). Reporta si la actualización automática está encendida y si tiene efecto (`DISABLE_AUTOUPDATER` sin `FORCE_AUTOUPDATE_PLUGINS`). Resume el CHANGELOG entre la versión instalada y la de referencia, y ofrece `claude plugin marketplace update` + `claude plugin update`.
  - **Clon**: lo revisa si hay `NEB_HOME` (adelante, atrás, divergido, con cambios sin confirmar). Solo ofrece clonar si el usuario va a contribuir.
  - **Cierre**: pide una sesión nueva o `/clear`, porque `/reload-plugins` no vuelve a inyectar el arranque. Si no hay espacio de trabajo, `/wakeup`.
  - Cada cambio de configuración pasa por un menú, y los comandos `/` los teclea el usuario.

### Changed
- **`README.md`** § "Cómo empezar": el prompt para copiar sustituye a los comandos `/plugin`, `/reload-plugins` y `/wakeup`.
- **`docs/user-guide.md`** § "Instalar": el prompt pasa a ser la vía corta y los comandos quedan como vía manual. § "Mantener Neb al día": el mismo prompt aparece como forma de actualizar.
- **`methodology/platform-assumptions.md`**: `INSTALL.md` aparece entre los usos de R28 y R29.
